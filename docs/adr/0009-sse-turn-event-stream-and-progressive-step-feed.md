# Real-Time SSE Turn Event Stream and Progressive Chat Step-Feed Protocol

AegisSRE streams real-time security inspection and tool execution progress from the ADK Go v2 `runner.Runner` and `AegisSecurityPlugin` to the browser over Server-Sent Events (`POST /api/sessions/{sessionId}/turns/stream` and `POST /api/sessions/{sessionId}/confirmations/stream`), while implementing the batch JSON endpoints (`POST /api/sessions/{sessionId}/turns` and `POST /api/sessions/{sessionId}/confirmations`) on top of the exact same `ExecuteTurnStream` / `ResolveConfirmationStream` pipeline. A thread-safe `TurnEventSink` attached to the turn invocation flushes six typed SSE frames (`turn.started`, `boundary.step`, `wire.record`, `text.delta`, `a2ui.card`, and `turn.completed`) via `http.Flusher` the instant each boundary verdict (`B1`..`B6`), outbound wire call, reasoning text delta, or `A2UI v0.9` card is produced, allowing `app.js` (`fetch` + `ReadableStream`) to mount the `.step-feed` immediately and append live `.step-row` items with `LIVE`/`FIXTURE` `Source Provenance` badges without artificial client-side delays. The `internal/evals` harness grades both the final `TurnResult` and the ordered `TurnStreamEvent` frame sequence across all 10 Red-vs-Blue trajectories and multi-turn `Persona Session Partition` follow-ups in offline CI (`ScriptedToolPlannerLLM`) and opt-in live GKE/Agent Platform mode (`AEGIS_LIVE_EVALS=true`).
