# Dual-Backend 3LO Token Broker and Persona-Partitioned Credential Vault

AegisSRE implements ADK Go v2's `auth.Provider` interface (`google.golang.org/adk/v2/auth`) using a dual-backend Token Broker that supports both Google Cloud IAM Connector (`google.golang.org/adk/v2/auth/gcp`) and a built-in Direct OAuth 2.0 3LO authorization code exchanger for Google Gmail (`gmail.readonly`), Atlassian Jira Cloud (`auth.atlassian.com`), and GitHub OAuth Apps. Credentials are partitioned by `(OperatorSessionID, PersonaID, ProviderID, Scopes)` and injected exclusively at the HTTP transport layer (`auth.Transport`) outside the LLM context window, enabling instant live comparison between `Alice (SecOps)` and `Bob (Contractor)` without browser session churn or IAM Connector preview allowlist blockers.
