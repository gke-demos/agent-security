# Agent Registry Discovery, Agent Gateway UAP Enforcement, and Gemini Enterprise A2A Wire Compatibility

AegisSRE discovers governed MCP servers (`logging.googleapis.com/mcp`, `container.googleapis.com/mcp`, GitHub, Jira) and the `Sandbox Remediator` A2A peer via `google.golang.org/adk/v2/agentregistry` (with a local manifest fallback) and enforces `Agent-to-Anywhere` Unified Access Policy (UAP) per-tool CEL rules that permit read-only diagnostics (`logging.entries.list`, `container.clusters.get`) while denying destructive tools (`container.clusters.delete`). On its inbound `/a2a` surface, AegisSRE advertises `"text/plain"` alongside `"text"` in `/.well-known/agent-card.json`, deduplicates consecutive identical `TextPart`s sent by Gemini Enterprise Discovery Engine, and extracts forwarded `serverSideOauth2` Bearer tokens into the Token Broker.
