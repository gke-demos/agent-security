# Unified ADK Go v2 Runner and Security Lifecycle Plugin Architecture

AegisSRE executes both the five canonical Red-vs-Blue Security Scenarios and arbitrary free-form Operator prompts through a single ADK Go v2 `runner.Runner` wrapping the `Triage Orchestrator` (`llmagent`) with all eight governed `functiontool` tools and a registered `Security Lifecycle Plugin` (`AegisSecurityPlugin`, `plugin.Config`). `AegisSecurityPlugin` enforces all six security boundaries dynamically across ADK callbacks: `BeforeRunCallback` injects per-turn `SecurityPosture` and `Persona` state; `BeforeModelCallback` screens and SDP-redacts user inputs (`SanitizeUserPrompt` + `DeidentifyContent`, short-circuiting `GenerateContent` on prompt injection); `BeforeToolCallback` enforces Agent Gateway UAP CEL rules, resolves per-persona 3LO credentials via `TokenBroker` (returning a `ConsentChallenge` with `SkipSummarization = true` when missing), and triggers native `ctx.RequestConfirmation` (`adk_request_confirmation` pause/resume) on state-mutating tools; `AfterToolCallback` screens and SDP-redacts untrusted tool and `Sandbox Remediator` A2A outputs before they enter session history; and `AfterModelCallback` / `OnEventCallback` validate `A2UI v0.9` cards and emit real-time boundary telemetry. To keep `go test` 100% deterministic offline while supporting open-ended live tool chaining, `llmagent.Config.Model` uses a dual-backend `model.LLM` seam (`GeminiAgentPlatformLLM` on Gemini Enterprise Agent Platform when `AGENT_PLATFORM_LIVE_LLM=true`, with automatic fallback to `ScriptedToolPlannerLLM`), and partitions ADK `session.Session` keys into a `Persona Session Partition` (`SessionID:Persona`) whenever `TokenBrokerEnabled` is active so switching from `Alice` to `Bob` mid-conversation cannot leak restricted tool outputs from session history.
