# Per-Provider Hybrid Live and Fixture Source Connectors with ADK Go v2 Reasoning

AegisSRE runs an ADK Go v2 `llmagent` (`google.golang.org/adk/v2/agent/llmagent` on Gemini Enterprise Agent Platform `gemini-2.5-flash`) paired with per-provider hybrid External Source connectors (`Gmail`, `Jira Cloud`, `GitHub`, `Cloud Logging`, `GKE`, `Model Armor`, `Agent Registry`, and `Agent Substrate v0.5.0`). Each External Source independently upgrades to `LIVE` execution whenever its runtime credentials or endpoints are present and falls back to deterministic `FIXTURE` execution when unconfigured or offline, recording explicit `Source Provenance` (`LIVE` vs. `FIXTURE`) on every `Boundary Trace Waterfall` event, outbound wire record, and the `GET /api/sources/status` status row inside the `⌘K` Demo Controls modal. Live GitHub reads and Step-Up-approved Pull Requests target a dedicated companion `Target Repository` (`gke-demos/aegis-checkout-target`, configurable via `GITHUB_TARGET_REPO`), `TokenBroker` accepts both real 3LO browser OAuth redirects and pre-seeded persona tokens (`ALICE_*_TOKEN` / `BOB_*_TOKEN` provisioned via `hack/setup-live-sources.sh`), and local workstation runs auto-bridge untrusted `go test` verification to the active GKE cluster's Agent Substrate `v0.5.0` gVisor `WorkerPool`.
